# 从课程组件到完整作品：集成顺序与验收合同

## 当前事实

本轮已另行验证本地 PostgreSQL 的 documents RLS 和数据重启读取，并准备 Agnes 单次接入与无密钥云展示包；详情见 [零预算记录](zero-budget.md)。当前 Web API 仍读文件，尚未接入 PostgreSQL 或真实模型。

全套教材已提前准备。仓库提供一条已运行的**词法证据检索 Web 演示**，以及独立的入库、向量、在线 RAG、审批、记忆、MCP 等参考实验。不是所有实验都已经接到同一个服务里，也不是已完成生产应用。

离线演示链：`Markdown → Document → 词法检索 → FastAPI → TypeScript 页面`。

目标产品链：

```text
授权资料 → 版本/分块 → 嵌入与词法索引
                             ↓（服务端 ACL）
浏览器 → 认证 → 检索 → 证据充分性判断 → 生成 → 引用校验 → 展示
             └→ 草稿 → 审批记录 → 工具重新授权 → 幂等写入/审计
PostgreSQL：身份关联、版本、审批、状态；Qdrant：块向量和过滤
评测/追踪：数据外发与保留控制；记忆：按用户授权保存和删除
```

## 每个接口应携带什么？

| 边界 | 最小数据合同 | 不允许发生什么 |
|---|---|---|
| 文档→块 | document_id、version、chunk_id、source、offset/page、text、tenant/ACL_version | 不带来源直接写向量；旧版本残留 |
| 检索请求 | 服务端验证的 actor、question、k、活动索引版本 | 浏览器/模型自行声明可访问租户 |
| 检索结果 | 仅可见 chunk、相对来源、版本、检索分数与检索器名 | 把分数当可信概率；泄露不可见标题 |
| 生成输入 | 已授权证据、问题、结构化输出 schema、预算 | 将文档中的指令提高到系统权限 |
| 生成结果 | answer、citation_ids、insufficient_evidence | 引用不存在、无依据断言、拒答却带不一致引用 |
| 审批→工具 | 服务端读取的身份/角色、草稿哈希、审批记录ID/到期、幂等键 | 客户端自报 approved=true 就执行 |
| 追踪 | 允许的元数据、脱敏策略、保留期 | 默认上传所有原文、密钥或客户数据 |

## 集成练习：只改一条边

下面是阶段完成时的集成任务，不是现在要求你独立实现。导师会按照现有课的完整示例逐段带做；验收未通过不得将组件测试当最终集成通过。

1. **阶段 2→3：** 将 live_rag 的整文输入替换为 chunks 输出；Qdrant payload 保存块 ID/父ID/版本/来源。保持现有文档级题集，以父 ID 评测；另外验证块级引用偏移。新旧索引版本用不同活动指针，失败不切换。
2. **阶段 3→5：** 先保留 `/api/search` 作为确定性检索对照，再增加 `/api/answer`。服务端身份传入检索器，不能先全库在线生成再过滤。LLM 失败应返回可诊断错误而非“没有答案”。API 的请求取消需向在线模型任务传播。
3. **阶段 5：** 将固定演示令牌替换为可信 OIDC/JWT 验证和数据库 ACL；完成双向越权、撤权、来源读取、缓存、日志隔离测试后，才允许导入真实授权资料。RLS 测试必须用实际应用角色，不用管理员。
4. **阶段 6：** 把 LangGraph 的 draft/approve 状态与受保护审批记录关联；增加请求者对 thread 的权限验证。工具从存储加载审批，检查哈希/角色/时效。不可接受模型提供的 Approval。先接模拟外部 API 验证超时和远端幂等，再申请接真实工单系统。
5. **阶段 7：** 将偏好记忆放进带 user/tenant/TTL 的存储；明确删除传播到缓存、向量和日志。接入允许列表追踪后检查服务端实际上传内容，不能只检查前端是否隐藏。
6. **阶段 8：** 选择一个部署方案，补 TLS、secret 注入、数据库持久卷/托管配置、健康与 readiness、备份恢复、限流、回滚。费用和服务申请需用户确认，本仓库不自动创建云资源。

## 最终集成验收必须包含

- 正常题：答案逐个断言由引用支持，引用跳转到正确版本/位置。
- 无答案/模糊题：证据不足不编造，缺上下文时澄清而不是强行选文档。
- 冲突/过期题：明确版本和不确定性，不混用互相矛盾规则。
- 权限：检索、父文档、缓存、会话、记忆、来源接口、日志、工具均隔离。
- 提示注入：恶意内容只能作为资料，无法调用未经授权的工具或泄露配置。
- 人工审批：拒绝、不存在、过期、撤销、内容变化和跨用户审批均不可写。
- 重试：同请求不重复；不同 payload 同 key 报冲突；断网/服务重启有可解释状态。
- 运行：浏览器取消、模型超时、限额、stream 中断、持久化故障均有测试或演练。

这些是作品毕业条件，不是当前已通过的清单。最新实际验证范围看 [verification.md](verification.md)。
